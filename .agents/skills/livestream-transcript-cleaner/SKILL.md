# 女装直播文稿清洗

1. 通读原稿并标记每款所有行区间。相同款跨区间合并，不同款分开。按要求覆盖每款；具体款名从已有属性提取。先报款名、行区间、预计删除类型及疑点，待确认后产稿。
2. 删除链接、发货、现货、几天飞、太阳、身高体重、单量、尺码标签、闲聊、语气称呼词及字面重复。尺码建议至多保留一条且须通过禁词筛查。疑似近义重复、混有卖点的句子、ASR 修正和残句补写先报告。稿件照录原话，允许按已确认的痛点前置规则移动句子。素材不足按实际供给。
3. 每款交两份 TXT，清洗版保留全量合格素材，切片版通常 30–70 秒，按钩子、种草、引导组织。穿搭展示若适用，沿用用户确认的 0–3 秒特写、3–10 秒上身及场景、10–25 秒多场景、25–35 秒面料细节、末段可用尺码建议。按实际口播时间复核。
4. 成稿一行一句、无标签及标点，原行区间列在报告中以便回查。逐项核对款式覆盖、原话一致性、禁词和时长。清洗版与切片版按确切款名命名，重做加版本号。交付文件、稿件全文、改动明细与验证结果。
